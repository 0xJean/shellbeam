# ShellBeam v0.1.10

## 更新内容

- **一次性验证码登录（2FA）：** 支持 keyboard-interactive 认证。服务器在密钥或密码之后要求验证码（Google Authenticator、Duo 等 PAM 方案），或只提供 keyboard-interactive 时，终端标签页会弹窗询问，最多等待 3 分钟。保存的密码会自动回答一次密码提示，其他问题交给你填写。
- **SSH Agent 认证：** 桌面端新增"Agent"凭据类型，依次尝试 Agent 中的每个身份（ssh-agent、1Password、Pageant、Windows OpenSSH），Vault 中不保存任何密钥。
- **文件类型图标：** SFTP 和本地文件面板按文件名和扩展名显示类型图标（Dockerfile、compose、README、.env、常见语言和配置文件等）。
- **软链接显示：** 软链接带链接角标并显示 `→ 目标`，失效链接划线标出。
- **终端关键字高亮：** 日志中的失败、警告、成功字样和 IPv4 地址分别着色。只给程序未自带颜色的文字上色，全屏程序不受影响。可在 设置 > 终端 中关闭。

## 安全修复

- **AI API Key 存入 Vault：** 模型 API Key 不再以明文保存在本地存储，改存入当前 Vault，仅在解锁期间保留在内存中。升级后首次解锁时自动迁移旧 Key。
- **AI 对话与命令历史加密：** AI 对话记录（含终端输出和命令结果）和终端输入历史改用 Vault 密钥加密保存（AES-256-GCM）。旧版的明文记录会在解锁时加密，然后删除。
- **发送给模型前脱敏：** 提示词、终端输出、命令结果和主机信息在发给任何 AI 后端（API 服务或 Claude Code / Codex CLI）前，会遮盖私钥、URL 中的凭据、Bearer Token、常见 Token 格式、密码参数和密钥赋值。默认开启，可在 AI 设置中关闭。
- **删除 Vault 时一并清理：** 删除 Vault 时也会删除它加密保存的命令历史和 AI 对话。

## 问题修复

- **指向目录的软链接可以打开：** 以前文件列表把软链接本身当作普通文件，指向目录的链接（例如部署目录里的 `current → releases/…`）无法进入。现在会解析链接，按目标的类型显示。

## 升级须知

- **AI Key 需要解锁 Vault：** Vault 锁定时 AI 助手无法使用已保存的 Key。AI Key 会出现在钥匙串列表中，并像其他 Vault 密钥一样随局域网同步到已配对的设备。每个 Vault 单独保存自己的 Key。
- **2FA 仅限终端标签页：** SFTP 面板、后台监控、计划任务和 MCP 连接不会弹窗询问验证码，遇到要求验证码的服务器会报"需要验证码"。
- **暂不支持 Agent 转发。**
- 应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控记录和审计。桌面升级不升级或重新部署 ShellBeam Server、监控探针和服务端扩展。

## Highlights

- One-time-code sign-in: keyboard-interactive authentication with a dialog in terminal tabs, for servers that ask for a code after a key or password, or offer only keyboard-interactive.
- SSH agent credentials on desktop (ssh-agent, 1Password, Pageant, Windows OpenSSH); nothing is stored in the Vault.
- File panes show file-type icons and symlinks with their targets; links to directories can be opened.
- Terminal keyword highlighting for errors, warnings, successes and IPv4 addresses, only on text without its own colour. It can be turned off in Settings.
- Security: AI API keys move into the Vault, AI conversations and command history are encrypted with the Vault key, and secrets are masked before anything is sent to a model.
- Upgrade notes: AI keys need an unlocked Vault; code prompts appear only in terminal tabs; agent forwarding is not supported yet.
