# ShellBeam v0.1.17

本次版本重点修复 AI 助手执行长命令或开关面板时引发的 SSH 交互会话断线重连问题，新增按服务器独立记忆 AI 助手面板开关状态，并升级发版自动化签名公证流水线与发布文档。

- **修复 AI 助手执行命令导致的 SSH 断线重连（Rust 交互终端引擎）**：
  - 将阻塞式写循环重构为带背压的非阻塞 `VecDeque<u8>` 写队列（每轮 4 KB 切片），与 `channel.read()` 交替排空远端 PTY 回显与 `WINDOW_ADJUST` 窗口更新包；不再将 `libssh2` 通道窗口暂满时返回的 `Ok(0)`、`WouldBlock` 或 `Interrupted` 误判为致命错误 `closed(-1)`。
  - 移除 `ssh2::Channel` 上多余的 `flush()` 调用，在关闭标签页前保留最多 1.5 秒优雅刷完已入队输入。
  - 通过 `ResizeQueue` 分离 `in_flight` 与 `pending` 尺寸，避免窗口缩放或开关 AI 面板触发的瞬时 PTY resize 失败拆断会话或丢弃最新终端尺寸，并为 `resize` / `keepalive` / `close` 增加有界超时。
- **按服务器持久化 AI 助手开关状态与分屏快捷键优化**：
  - 按每台服务器所属的 `vaultId + hostId`（回退 `vaultId + username@hostAddress`）独立记忆最后一次 AI 助手面板开关状态，在切换标签、重连、切换 Vault 或重启应用后自动恢复。
  - `⌘I / Ctrl+I`、`⌘⇧F`、`Ctrl+Space` 优先路由到当前获得键盘焦点的可见终端窗格（支持分屏右侧点击聚焦），不再误切后台隐藏标签页。
- **发布流水线与签名公证加固**：
  - 升级 GitHub Release 流水线支持 macOS Universal（Apple Silicon + Intel）双重公证（`.app` + 外层 `.dmg`）、Android 签名校验、自动生成 `SHA256SUMS` 与未签名自动保留 draft 的安全门禁，并补充端到端 `docs/release-process.md`。

## 升级说明

应用标识保持 `app.shellbeam`，直接升级即可无缝保留现有保管库、主机、凭据、AI 会话记录与偏好设置。

## English

ShellBeam v0.1.17 fixes SSH interactive session disconnects triggered by AI assistant command execution and panel resizing, adds per-server persistence for the AI assistant panel open/closed state, and hardens the release signing and notarization pipeline:

- **Eliminate SSH Disconnects on AI Command Execution**:
  - Replaced the blocking channel write loop with a bounded, interleaved non-blocking `VecDeque<u8>` write queue (4 KB slices alternating with `channel.read()`), so remote PTY echo and `WINDOW_ADJUST` packets drain continuously and `libssh2` backpressure (`Ok(0)` / `WouldBlock` / `Interrupted`) no longer triggers spurious `closed(-1)` reconnects.
  - Removed unnecessary `ssh2::Channel::flush()`, added a 1.5 s graceful input flush on tab close, separated in-flight vs pending PTY dimensions in `ResizeQueue`, prevented transient PTY resize errors from terminating live sessions, and bounded `WouldBlock` retry budgets.
- **Per-Server AI Assistant Panel Persistence & Split-Pane Shortcut Routing**:
  - Persists each server's last AI assistant open/closed state independently (keyed by session `vaultId + hostId`, falling back to `vaultId + username@hostAddress`) across reconnects, tab reopens, vault switches, and app restarts.
  - Routes `Cmd/Ctrl+I`, `Cmd/Ctrl+Shift+F`, and `Ctrl+Space` to the focused visible terminal pane (including split right panes), falling back to the selected tab when focus is outside terminal panes.
- **Release Signing & Documentation Hardening**:
  - Upgraded `Release` CI for Universal macOS (`.app` + outer `.dmg` notarization and `spctl`/`stapler` checks), signed Android APK/AAB staging, automatic `SHA256SUMS`, unsigned draft safety gate, and added `docs/release-process.md`.
