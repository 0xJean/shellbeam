# ShellBeam v0.1.15

本次版本将终端 AI 助手全面升级为轻量级运维 Agent 客户端，新增静默只读 SSH 执行与输出捕获增强、16 家国内外 API 服务商与 4 款本地 CLI Agent 支持、桌面端全功能可拖拽持久化分割栏，并完成了全仓库 ESLint / Rust Clippy 质量治理与稳定性修复。

- **AI 助手静默 SSH 执行与捕获增强**：
  - 有界只读排查命令优先走独立非交互 SSH 通道静默执行，返回精确 `exitCode` 与干净的 `stdout`/`stderr`，消除日志中含 `error` 字样导致的误判，同时保留「在终端运行」按钮并在认证/Vault 异常时自动回退至交互终端。
  - 优化输出截断与终端回读：支持首尾保留截断（200 逻辑行 / 16KB，保留前 30 行 + 后 170 行）、`isWrapped` 折行重组及过滤回显行，并在只读命令分类中安全放行统计/过滤类 `awk` 脚本（保持 fail-closed 严格拦截写文件与外部命令调用）。
  - 升级通用运维 System Prompt（API 与本地 CLI 同步），强化先统计分布/总量再定向深挖、控制命令输出量及结论结构化输出。
- **完整服务商与本地 CLI Agent 矩阵**：
  - API 模式扩展至 **16 家服务商**（按国际 / 国内 / 本地与自定义分组：OpenAI、Anthropic、Google Gemini、OpenRouter、xAI、Groq、DeepSeek、通义千问、智谱 GLM、Moonshot Kimi、硅基流动、火山方舟、MiniMax、Ollama、LM Studio 及 Custom），均支持 Vault 加密存储密钥与每服务商独立代理 Base URL。
  - 本地 CLI Agent 新增 **Gemini CLI** 与 **OpenCode**，与 Claude Code、Codex CLI 统一使用独立隔离临时目录、禁止用户输入进入 argv 并严格拒绝未授权工具调用。
- **轻量 Agent 客户端交互体验**：
  - **模型切换器 v2**：支持全部 4 款 CLI 预设模型（含 Codex CLI `gpt-5.4` / `gpt-5.4-mini` / `gpt-5.3-codex` / `o4-mini` / `o3`）与推理强度（Effort）切换、API 动态模型列表拉取/搜索/一键刷新及最近使用记录。
  - **单主机多会话 Vault 历史**：每台主机最多保存 20 条 Vault 加密会话，支持新建/切换/删除，并在写入队列内先读最新历史再按会话合并更新，避免同一主机双终端并发保存互相覆盖。
  - **高效排查辅助**：安全 Markdown 渲染（支持表格、标题、列表与可复制代码块）、连续自动只读步骤折叠时间线、终端划词浮窗「问 AI」引用附带上下文，以及自定义运维规则配置。
- **桌面端可拖拽且本地持久化的分割栏**：
  - 为 AI 助手面板、终端右侧边栏、主导航栏、工作区列表栏与 SFTP 双栏统一接入可拖拽分割手柄，自动记忆到本地并在下次打开时还原，支持双击重置、键盘方向键微调、视口防溢出钳制与跨窗口同步。
- **稳定性与代码质量治理**：
  - 修复 `PcLayout` 刷新回调不稳定引起的渲染循环风险与快速点击时的 ref 同步竞态；清理全仓库 ESLint 与跨平台 Rust Clippy 告警并在 CI 中启用零告警门禁。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和历史审计记录；旧版单会话 AI 历史将自动无缝迁移至多会话加密格式。

## English

ShellBeam v0.1.15 upgrades the terminal AI Assistant into a lightweight Ops Agent client with silent read-only SSH execution, 16 API providers and 4 local CLI agents, draggable & persisted desktop split panels, and repository-wide lint/Clippy/stability improvements:

- **Silent SSH Execution & Enhanced Output Capture**:
  - Bounded read-only checks run silently over an independent non-interactive SSH exec channel with exact exit codes and clean stdout/stderr (eliminating false failure detection when logs contain `"error"`), with an explicit **Run in terminal** action and automatic fallback on auth/Vault issues.
  - Upgrades capture with head+tail truncation (200 logical lines / 16KB), `isWrapped` logical-line rejoining, echoed command filtering, hardened fail-closed read-only `awk` classification, and a universal ops System Prompt synced across API and CLI backends.
- **Expanded API Provider & Local CLI Agent Matrix**:
  - Adds **16 API providers** grouped across Global, China, and Local/Custom (OpenAI, Anthropic, Google Gemini, OpenRouter, xAI, Groq, DeepSeek, Qwen, Zhipu GLM, Moonshot Kimi, SiliconFlow, Volcengine Ark, MiniMax, Ollama, LM Studio, Custom) with Vault-encrypted keys and per-provider proxy Base URL overrides.
  - Adds **Gemini CLI** and **OpenCode** alongside Claude Code and Codex CLI, all running in isolated scratch directories with zero user input in argv and strict tool-use rejection.
- **Lightweight Ops Agent UX**:
  - **Model Switcher v2** with curated CLI presets (including Codex CLI `gpt-5.4` / `gpt-5.4-mini` / `gpt-5.3-codex` / `o4-mini` / `o3`), Reasoning Effort selector, live API model discovery/search/refresh, and per-backend recent models.
  - **Vault-Sealed Multi-Thread History** (up to 20 threads per host) with queued read-modify-write persistence so concurrent sibling terminals on the same host never overwrite each other's threads.
  - XSS-safe **Markdown rendering** (tables, headings, copyable code blocks), collapsible automatic step timelines, terminal selection **"Ask AI"** quote chips, and Custom Ops Rules.
- **Draggable & Persisted Desktop Split Panels**:
  - Adds pointer/keyboard resize handles persisted to `localStorage` (with double-click reset, viewport clamping, and cross-tab sync) across the AI Assistant, Terminal Right Sidebar, Main Nav Sidebar, Workspace Server List, and SFTP Dual Pane.
- **Stability & Quality Gates**:
  - Stabilizes `PcLayout` refresh callbacks and layout-commit ref synchronization, clears repository-wide ESLint and cross-platform Rust Clippy warnings, and enforces strict zero-warning CI gates.
