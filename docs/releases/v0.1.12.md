# ShellBeam v0.1.12

本次版本重构并统一了 `shellbeam-server` 与监控探针（Probe）的集成体验，确立“原生 SSH 监控 + Server 探针增强监控”两套兼容的渐进式监控体系。

- **渐进式两层监控模型**：第一层为客户端原生无代理 SSH 监控（开箱即用，实时采集 CPU、内存、磁盘等核心指标）；第二层为 `shellbeam-server` + 探针增强监控（客户端原生监控的升级版，解锁 24/7 连续历史曲线、离线告警与多机聚合监控）。
- **连接/新建主机时一键可选探针**：在新建与编辑主机表单中提供直观的“安装监控探针（增强监控）”卡片开关；若当前 Vault 尚未配置 Server，表单内直接展开内联连接面板（支持账号密码登录、API Key 或全新节点初始化），保存主机时自动完成 Server 接入、节点注册、环境预检与探针安装，无需跳出表单前往设置页。
- **仪表盘集中式探针控制中心**：在左侧主导航“仪表盘”顶部新增 Server 状态与控制栏，并新增专属“探针管理（Probes）”标签页，提供全量主机探针状态矩阵、覆盖率统计、按状态筛选、批量安装以及单机升级/回滚/卸载（平滑退回原生 SSH 监控）。
- **常驻探针状态徽章與工作区监控卡片**：主机卡片与工作区头部常驻展示探针版本与健康状态徽章，点击即可打开集中探针管理弹窗；下线旧版独立本地采集器设置入口，彻底消除概念与入口混淆。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和历史审计记录。原生 SSH 与 Server 探针模式切换保留已有凭据、节点绑定与历史监控数据。

## English

ShellBeam v0.1.12 streamlines `shellbeam-server` and monitoring probe integration with a unified two-tier progressive monitoring experience:

- **Two-Tier Progressive Monitoring**: Tier 1 provides zero-setup client-native SSH monitoring; Tier 2 upgrades hosts with `shellbeam-server` and a managed probe for 24/7 continuous history, offline alerting, and fleet-wide aggregation.
- **Inline Server Connection & Auto-Install on Host Save**: Toggle probe installation directly when creating or editing a host. If no Server is configured yet, an inline connection panel lets you authenticate or initialize a Server on the spot and automatically runs preflight and probe installation upon saving.
- **Centralized Fleet Probe Control Center**: Added a top Server status bar and a dedicated **Probes** tab in the Fleet Dashboard for inspecting all hosts, batch-installing probes, and managing lifecycle actions (health check, upgrade, rollback, or uninstall back to native SSH).
- **Persistent Probe Badges & Unified Workspace Card**: Host cards and workspace headers now display persistent probe status badges that open the management dialog directly, retiring the legacy standalone local agent UI.
