# ShellBeam v0.1.5

## 更新内容

- 重整主机页的信息层级：突出主机名称与连接操作，保留地区、基础指标和监控时效；告警、服务与任务、监控分区展示，诊断与审计详情按需展开。
- 横向滚动控件采用 ShellBeam 主题，缩小视觉占用，同时保留拖动、方向按钮及键盘操作。
- 包含自 v0.1.4 以来已合入主分支的 Terminal + Ops 功能：统一主机目录与多连接、可选监控服务、原生告警和通知设置，以及有确认与审计的探针和扩展生命周期管理。
- ProxyJump 覆盖 SSH、SFTP、端口转发及运维采集；改进 SFTP 响应与跨会话状态恢复。
- MCP 增加代码片段查询与受控执行、结构化只读运维、文件目录浏览及多连接授权。内置终端助手另支持本机 Claude Code / Codex CLI 生成建议命令。

## 数据与升级

- 正式应用标识仍为 `app.shellbeam`。本次布局改动不修改主机资料、Vault 凭据、监控记录或 OperationJob 审计。
- 历史失败记录与原始任务标识保留在诊断详情中；结果未知仍需先检查远端状态，不自动重放操作。
- 监控为可选功能；日常管理使用 ShellBeam 原生页面。服务端与探针的安装、升级、回滚或卸载仍需在 App 内明确操作，桌面升级不会自动部署它们。
- 本地 `ShellBeam Ops Acceptance` 使用独立应用标识，安装正式版不会把验收 Vault 自动迁移到正式版。

## Highlights

- A clearer host overview, primary Connect action, compact resource meters and separate alert, task and monitoring sections. Raw diagnostics remain available on demand.
- Themed horizontal scrolling with existing pointer and keyboard controls.
- Includes the Terminal + Ops, optional native monitoring, audited lifecycle, ProxyJump, SFTP and MCP improvements merged since v0.1.4.
- Existing data, credentials and audit records are retained. Unknown remote operations are inspected before an explicit retry.

## 下载与范围

- 可用平台、架构、签名和公证状态以本次 Release 实际附件及核验结果为准。不会把旧版本附件标为新版本。
- CLI 助手需要本机安装兼容版本并完成自身登录；成功生成后由用户决定是否在终端执行。MCP 需要单独授权。
- 本次 GitHub Release 不包含新的 iOS / TestFlight 构建。
