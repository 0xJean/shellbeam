# ShellBeam v0.1.4

## 更新内容

- 正式采用深色 Hex Channel（03）Logo，统一应用界面、favicon 和各平台图标。
- AI 模型列表支持按需从供应商刷新、本地缓存及手动输入模型 ID，切换供应商时分别保留配置。
- 增加 Codex 和 Claude Desktop 的 MCP 接入引导、配置格式和本机桥接检查。不会自动修改外部客户端配置，也不内置部署引擎。
- 修复 Windows SSH 内存私钥认证及 Linux 浏览器导航、PTY 的跨平台编译问题。

## Highlights

- Adopted the dark Hex Channel identity across all application icon assets.
- On-demand model discovery, cached model lists and manual model IDs.
- Codex and Claude Desktop MCP setup guidance and authenticated local bridge diagnostics.
- Cross-platform compilation fixes for SSH, browser navigation and local PTYs.

## 使用说明 / Notes

- MCP 默认关闭，执行命令和文件访问仍需单独授权；本机桥接检查不连接远程服务器。
- Windows 本地终端尚不支持，远程 SSH 终端不受此限制。
- 安装包及签名状态以本次 Release 实际附件和发布说明为准；iOS 通过 TestFlight 分发，不提供可直接安装的 GitHub IPA。
- 本 Release 位于私有 app 仓库，下载需要仓库访问权限。
