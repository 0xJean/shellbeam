# ShellBeam v0.1.7

## 更新内容

- **全新 v3 界面：** 重做全局框架（侧边栏、标签栏、命令面板、确认弹窗），以及主机、仪表盘与监控图表、VPS 资产、部署项目、工具页、设置、欢迎与锁屏页。移动端改为五个固定标签和工具中心。
- **AI 助手：** 终端旁改为对话面板，可读取命令输出、建议下一步（按 Tab 采用）、在需要你决定时列出选项，并可带上这台服务器的已知信息。每台服务器可单独选择执行模式：每步确认（默认）、只读自动或连续执行；高危命令始终需要确认。
- **主机工作空间：** 支持列表和桌面两种布局。桌面布局下每个应用是一个窗口，可最小化到任务栏、最大化，切到后台时内容保持。
- **主题：** 统一为 8 个主题，每个都有亮色和暗色，由亮暗模式决定显示哪一面；默认是 Aqua。自定义颜色保留，并同时作用于亮暗两面。终端配色默认跟随应用主题，界面语言默认跟随系统，并新增多种界面风格。
- **监控探针：** 可从主机卡片按向导安装，或多选主机批量安装；安装前先做只读检查，向导可自动新建并关联监控节点。批量操作可重试未完成的主机。
- **Vault：** 各保管库的同步、删除、已知主机和历史记录互相隔离；主机可移到另一个保管库。锁定后会遮住整个应用，需要明确解锁。
- **使用教程：** 每一节都有界面演示，新增「主机工作空间」一节，并更新 AI 助手和监控内容。
- **修复与细节：** 关闭会话弹窗按主题显示并列出仍打开的标签页；从 Claude Code 会话启动时能正确检测本机 AI CLI；修复 VPS 资产页的滚动和布局问题。

## 数据与升级

- 应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控记录和审计。
- 已保存的配色不会被改掉：之前亮暗选了不同配色的用户仍按原组合显示，重新选择一个主题后统一。未保存过配色的用户会使用新的默认主题 Aqua。
- 桌面升级不升级或重新部署 ShellBeam Server、监控探针和服务端扩展。

## Highlights

- A new v3 interface across the app, including mobile.
- A docked AI assistant that reads command output, suggests the next step and runs by a per-server mode: ask every step, auto-run checks or run continuously. High-risk commands always wait for confirmation.
- List and desktop layouts for the host workspace.
- Eight themes, each with a dark and a light side. Custom accent colours remain available.
- Guided and batch monitoring probe installation, with a read-only check first.
- Stronger Vault isolation, moving hosts between Vaults, and a full lock screen.
- Existing data, credentials, grants and saved appearance choices are retained.
