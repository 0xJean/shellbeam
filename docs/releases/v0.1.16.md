# ShellBeam v0.1.16

本次版本带来全新现代 4 层主题体系、全量最新 AI 模型与自动发现、VPS 资产与续费追踪、主机舰队 UI 升级、AI 变更前自动备份与一键回滚护栏、SSH 一键网络与 IP 体检，以及双终端 AI 会话并发安全收口与 CI 发布流水线优化。

- **现代 4 层主题体系与视觉重设计**：
  - 推出 **8 套现代深浅配对主题**（Obsidian 默认、Tokyo Night、Catppuccin、Rose Pine、Nord、Graphite、Emerald Ops、Solarized），建立清晰 4 层表面色阶与高对比语义色。
  - 新增 **Glass 毛玻璃界面风格**，每套主题均配备专属 16 色终端 ANSI 配色，外观设置升级为可视化迷你工作台预览卡片，监控折线采用语义 4 色（CPU / 内存 / 磁盘 / 网络）与等宽数字 `tabular-nums`。
- **VPS 资产与续费追踪**：
  - 主机配置（新建与编辑）支持可选的资产续费记录：服务商、价格/币种/计费周期、到期日期、月流量配额与自动续费，并在 SQLite 中平滑自动迁移。
  - 主机卡片与列表直接展示 `到期 X天` / `已过期` 分级徽标，顶部 KPI 栏新增交互式 `到期 N` 一键筛选胶囊与多币种月均成本汇总。
- **主机总览与值班体验升级**：
  - 新增**地域健康胶囊条**（带国旗与 `在线/总数` 异常比值高亮），支持按地区一键过滤。
  - 排序扩展至**异常状态优先 / CPU / 内存 / 磁盘 / 到期时间**，并新增**「实时排序 / 冻结排序」开关**防止排查时行序跳动；主机运维抽屉新增 **24 段颜色状态走势条**。
- **AI 运维安全护栏与最新模型矩阵**：
  - 全量刷新 16 家 API 服务商与 4 款本地 CLI 的 2026 年 11 月最新官方模型目录（含 GPT-6.2、Claude 5.5、Gemini 4、Grok 4.7、DeepSeek V4 Pro、Qwen 4 Max 等），支持自动拉取 `/models` 实时模型列表与无缝切换。
  - 新增变更类命令**「备份后执行」与「一键回滚」**：修改配置前自动快照到 `~/.shellbeam-backups/`（保留最近 3 份），完整覆盖 `~/` 路径展开、`mv` 源/目标双备份、`sudo` 原属主保留、新建文件 `.absent` 标记与 heredoc 安全包裹。
  - 扩展敏感凭据脱敏范围（OpenRouter / xAI / Groq / Telegram Bot Token / `mysql -p` / `curl --user=` 与带空格引号密码），并彻底收口同主机双终端并发写入 AI 会话历史的所有边界条件。
- **SSH 一键网络与 IP 体检（零常驻 Agent）**：
  - 在主机运维抽屉内按需发起只读 SSH 体检，结构化展示出口 IPv4/IPv6 与 ASN 归属、Cloudflare / Google / 电信 / 联通 / 移动及自定义目标延迟丢包矩阵、OpenAI / Claude / GitHub / Netflix / YouTube 连通性，并支持一键复制 Markdown 报告。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和历史审计记录；旧版外观配色将在启动时无缝迁移至新版配对主题。

## English

ShellBeam v0.1.16 introduces a modern 4-layer theme system, refreshed Nov 2026 AI model catalogs with automatic discovery, VPS asset & renewal tracking, fleet dashboard UX upgrades, AI pre-edit backup & 1-click rollback guardrails, on-demand SSH network & IP diagnostics, and dual-terminal AI conversation concurrency hardening:

- **Modern 4-Layer Theme Redesign**:
  - Adds **8 curated dark/light theme pairs** (Obsidian default, Tokyo Night, Catppuccin, Rose Pine, Nord, Graphite, Emerald Ops, Solarized) with a structured 4-layer surface hierarchy, bespoke per-theme 16-color terminal ANSI palettes, a new **Glass** UI style, miniature workbench preview cards in Appearance settings, and semantic 4-color telemetry sparklines.
- **VPS Asset & Renewal Tracking**:
  - Adds optional billing metadata on hosts (provider, price/currency/cycle, expiration date, monthly traffic quota, auto-renew) backed by automatic SQLite schema migration and editable in both host creation and saved-host editors.
  - Displays countdown/expired badges on host cards and rows plus an interactive **Expiring N** filter pill and monthly cost summary in the fleet KPI bar.
- **Fleet Dashboard & Duty UX Upgrades**:
  - Adds a **Region Health Pill Strip** with country flags and highlighted `online/total` ratios for degraded regions.
  - Expands host sorting to **Health (issues first), CPU, Memory, Disk, and Expiring soonest**, adds a **Live / Frozen** sort toggle to stop rows from jumping during live inspection, and adds a **24-segment status history sparkline** in the Host Operations Drawer.
- **AI Ops Safety Guardrails & Refreshed Models**:
  - Updates all 16 API providers and 4 local CLI catalogs to the latest Nov 2026 models (GPT-6.2, Claude 5.5, Gemini 4, Grok 4.7, DeepSeek V4 Pro, Qwen 4 Max, etc.) with automatic background `/models` discovery.
  - Adds **Backup & Run** and **1-Click Rollback** for file-mutating AI commands (snapshotting up to 3 copies in `~/.shellbeam-backups/` with subshell isolation, `~/` expansion, move source+destination coverage, `sudo` ownership preservation, new-file `.absent` markers, symlink guards, and heredoc safety).
  - Expands secret redaction (OpenRouter, xAI, Groq, Telegram Bot tokens, `mysql -p`, `curl --user=` and quoted credentials) and closes all dual-terminal AI thread-book concurrency edge cases.
- **On-Demand SSH Network & IP Diagnostics**:
  - Runs a bounded, read-only SSH check from the Host Operations Drawer with zero resident agent required: Exit IPv4/IPv6 + ASN/location, multi-target latency & packet loss matrix (Cloudflare, Google DNS, China Telecom/Unicom/Mobile + custom target), AI/streaming reachability badges, and Markdown report copy.
