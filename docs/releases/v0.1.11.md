# ShellBeam v0.1.11

本次为维护版本，重点加强安装包运维验收与故障诊断。

- 修正自动化填写告警时长时与后台刷新之间的竞争：使用真实键盘替换，并核对失焦后的输入值及最终保存值，避免计划填写的 0 秒变成 300 秒。
- 增加只读的已保存告警时长、恢复起点和观察值诊断，便于定位恢复等待问题。
- 修正监控连接测试的异步等待，节点目录加载完成后再验证绑定流程。
- 停止每日定时安装包验收；PR、主分支推送、手动运行和版本发布仍保留相应验收。

本次没有新增监控策略或改变告警评估规则。原始失败运行未记录保存时长，不能断言该次一定保存了 300 秒；该竞争已在隔离环境复现，修复后的真实安装包验收已通过。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和审计。桌面升级不安装、升级或重新部署远端 ShellBeam Server、探针和扩展。

## English

Maintenance release improving packaged operations acceptance and diagnostics. Alert-duration entry now uses real keyboard replacement and verifies both the blurred input and persisted value. Read-only recovery diagnostics and deterministic mapping-catalog test synchronization improve failure analysis. Daily scheduled acceptance is removed; pull requests, main-branch pushes, manual runs and release acceptance remain enabled.

Existing data, credentials, grants, monitoring settings and audit history are retained. This release does not change alert evaluation semantics or deploy remote monitoring components.
