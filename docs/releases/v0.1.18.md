# ShellBeam v0.1.18

本次版本彻底修复新建 SSH 连接后终端黑屏或敲回车无响应的竞态故障，全面升级 AI 助手输入区与 Agent 风格模型选择器，并新增 Cursor Agent CLI 与 Devin CLI 本地智能体接入支持。

- **彻底修复终端建连后黑屏 / 无响应故障**：
  - 修复前端首次挂载终端时未等待后端已下发首帧内容就被清空的竞态问题，保留完整欢迎语与首个 shell 提示符。
  - 修复记忆打开的 AI 助手侧栏在建连瞬间抢占键盘焦点的问题（仅在用户主动触发或快捷键打开时聚焦输入框）。
  - 在 Rust `libssh2` 非阻塞交互循环中严格串行化出站写包、PTY Resize 与 Keepalive（新增 `KeepaliveState` 检测 `Outbound` 阻塞并及时排空），杜绝并发 `send_existing` 冲突导致的输入假死。
- **AI 助手输入区与 Agent 模型选择器重塑**：
  - 将模型选择器下沉至输入区底部工具栏，采用三栏定尺寸弹层（后端列表、支持搜索与跨标签页实时同步置顶收藏的模型列表、推理强度面板），切供应商页面尺寸零抖动；内置全部 6 款 CLI 与 16 家 API 供应商的品牌 Logo，并支持 Gemini API（2.5+ / 3.x+）的推理强度（Low / Medium / High）选择与快捷入口 `+ 添加 API...`（点击自动切至设置页）。
  - 将原先高饱和度的「最近输出」「服务器信息」双蓝色按钮整合为简洁的「上下文」菜单，消除视觉干扰。
  - 修复 macOS WKWebView 下中文/日文/韩文输入法按回车确认候选词被误判为发送消息的问题；优化连续执行进度显示（规划阶段显示「规划中…」，不再出现突兀的 `0/10`）。
  - 完善消息与命令输出复制体验（支持整条消息复制、自由划词复制与 `↑` 键回溯历史提问）。
- **新增 Cursor Agent CLI 与 Devin CLI 后端**：
  - 新增本地 `cursor-agent`（回退 `agent`）与 `devin` CLI 集成，采用隔离临时目录、只读/全工具禁用策略文件（`.cursor/cli.json` 与 `devin-config.json`）及流式解析保护，在保持零本地工具执行风险的前提下扩展可用 AI 引擎。
- **发布文档完善**：
  - 补充 `docs/release-process.md` 与 `AGENTS.md`，完整覆盖全部 6 处版本清单文件、iOS TestFlight 上传流程及官网自动同步校验。

## 升级说明

应用标识保持 `app.shellbeam`，直接升级即可无缝保留现有保管库、主机、凭据、AI 会话记录与偏好设置。

## English

ShellBeam v0.1.18 resolves blank/unresponsive SSH terminals on initial connect, overhauls the AI assistant composer and Agent-style model picker, and adds local Cursor Agent CLI and Devin CLI integrations:

- **Eliminate Blank / Unresponsive Terminals on Connect**:
  - Fixed a startup race where the terminal cleared or dropped initial SSH welcome output on mount, preserving the full MOTD and initial prompt.
  - Prevented a persisted open AI assistant panel from stealing keyboard focus from the newly connected terminal unless explicitly opened by the user.
  - Serialized outbound `libssh2` writes, PTY resizes, and keepalive packets in the Rust interactive I/O loop (`KeepaliveState` detects outbound blocking and drains in-flight keepalives even with queued input), eliminating `send_existing` stalls.
- **AI Assistant Composer & Agent Model Switcher Overhaul**:
  - Moved the model switcher into the composer footer with a fixed-size 3-pane popover (backends rail, searchable model list with cross-tab synced favorites, and reasoning effort rail) plus brand logos for all 6 CLI backends and 16 API providers, Gemini API `reasoning_effort` selection (Low / Medium / High), and a direct `+ Add API…` shortcut to Settings.
  - Replaced noisy blue context toggle chips with a clean unified Context popover.
  - Fixed macOS WKWebView CJK IME Enter key misfiring message submission; replaced confusing `0/10` step counters with `Planning…` / `Step N`; added reliable full-message/output copy, text selection, and `ArrowUp` prompt recall.
- **Cursor Agent CLI & Devin CLI Support**:
  - Added fail-closed local CLI adapters for `cursor-agent` (fallback `agent`) and `devin` with isolated scratch workspaces, explicit tool-deny policy configs (`.cursor/cli.json` and `devin-config.json`), and strict streaming output validation.
- **Release Process Documentation**:
  - Updated `docs/release-process.md` and `AGENTS.md` to cover all 6 version manifests, iOS TestFlight uploads, and automatic website release sync verification.
