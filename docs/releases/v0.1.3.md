# ShellBeam v0.1.3

## 更新内容

- 正式采用 V6 Logo，将原版蓝色光束与 V5 的玻璃质感终端符号融合，统一应用内、桌面、移动端和 favicon 图标。
- 新增本机 Agent 访问（MCP）：按客户端、Vault、服务器和能力授权查询资产及监控信息，并可选开放 SSH 命令与 SFTP 文件访问。
- 新增八节中英文使用教程，覆盖 Vault、首次连接、监控、日常工具、MCP、备份和排障，支持保存阅读进度。
- 新增 Driver.js 交互式引导，覆盖添加主机、服务器监控和 MCP 授权，支持退出、重看、深浅色和移动端。
- 增加 `npm run icons`，从 `app-icon.png` 统一生成各平台图标，避免应用内与安装包图标不一致。

## 使用说明

- MCP 默认关闭，仅向本机 Agent 提供信息和授权访问能力，不接管部署，不要求服务器安装 Agent。
- 执行命令、读取文件和写入文件需要单独授权。命令执行具有 SSH 账号的全部权限，文件开关不是命令沙箱。
- 引导不会自动保存主机、建立终端或授予权限，也不会伪造监控数据。
- 本次发布位于私有 App 仓库，需要仓库访问权限才能下载。
- V6 Logo 在 v0.1.2 标签推送后确定，因此使用新版本 v0.1.3；v0.1.2 保持未发布，不改写旧标签。

## Highlights

- Adopted the V6 identity across in-app branding, desktop and mobile icons, and the favicon. The existing beam meets the stronger glass terminal symbol.
- Scoped local MCP access to inventory, monitoring, SSH commands, and SFTP operations. Disabled by default; the agent owns deployment decisions.
- Eight bilingual guide chapters with reading progress, plus optional Driver.js tours for hosts, monitoring, and MCP permissions.
- Reproducible icon generation with `npm run icons` from the canonical `app-icon.png` source.
- No automatic host creation, terminal connections, permission grants, or remote agent installation.

## Platform Availability

- macOS Apple Silicon (M1 and later): `ShellBeam_0.1.3_aarch64-notarized.dmg`. The application and DMG are Developer ID signed, accepted by Apple notarization, and have stapled tickets. Gatekeeper validation passed.
- Download `SHA256SUMS.txt` alongside the installer to verify its SHA-256 checksum. An Intel-native installer is not included.
- Only verified installers attached to this release are available for download. Updated mobile icon resources do not imply a published mobile build.
- Windows and Linux have unresolved compilation failures. No installers for those platforms are included.
- Android release signing and iOS/TestFlight distribution are not included in this release.

- The final DMG was mounted read-only to verify version `0.1.3`, arm64 architecture, the V6 icon, and the application signature.
- DMG integrity, application and DMG notarization tickets, and Gatekeeper checks passed. The 50 generated PNG/XML resources matched a second icon generation.
