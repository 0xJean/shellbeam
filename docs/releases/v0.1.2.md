# ShellBeam v0.1.2

## 更新内容

- 新增本机 Agent 访问（MCP）：按客户端、Vault、服务器和能力授权查询资产及监控信息，并可选开放 SSH 命令与 SFTP 文件访问。
- 新增八节中英文使用教程，覆盖 Vault、首次连接、监控、日常工具、MCP、备份和排障，支持保存阅读进度。
- 新增 Driver.js 交互式引导，在真实界面中介绍添加主机、服务器监控和 MCP 授权；支持退出、重看、深浅色和移动端。
- 修复跨平台发布的 Rust 工具链配置、Linux 依赖冲突及未配置 macOS 签名时的构建失败。

## 使用说明

- MCP 默认关闭，仅向本机 Agent 提供信息和授权访问能力，不接管部署，不要求服务器安装 Agent。
- 执行命令、读取文件和写入文件需要单独授权。命令执行具有 SSH 账号的全部权限，文件开关不是命令沙箱。
- 引导不会自动保存主机、建立终端或授予权限，也不会伪造监控数据。
- 本次发布位于私有 App 仓库，需要仓库访问权限才能下载。Logo 保持不变。

## Highlights

- Scoped local MCP access to server inventory, monitoring, SSH commands, and SFTP operations. Disabled by default; the agent owns deployment decisions.
- Eight bilingual guide chapters with local reading progress, plus optional Driver.js tours for hosts, monitoring, and MCP permissions.
- Cross-platform release fixes for Rust toolchains, conflicting Linux packages, and missing macOS signing configuration.
- No automatic host creation, terminal connections, permission grants, or remote agent installation. The existing logo is unchanged.
