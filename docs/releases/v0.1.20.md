# ShellBeam v0.1.20

本次版本推出统一本地 Agent 注册表与 **一键开放本机 MCP 接入**，将 AI 助手与 MCP 统一收敛到全新 **AI 集成** 分区，并专项完善 **iPhone Duo** 右侧竖栏与移动端体验细节。

- **统一本地 Agent 清单与一键安全写入 MCP**：
  - 后端（`src-tauri/src/agents.rs`）与前端（`src/lib/agents.ts`）维护同一份本地 Agent 注册表，覆盖 **Claude Code、Codex CLI、Antigravity、Cursor、Gemini CLI、OpenCode、Devin CLI、Claude Desktop**，与终端 AI 助手完全同步，无需重复维护。
  - 自动扫描本机已安装的 Agent，为每个 Agent 签发独立令牌，并按各自配置协议（JSON `mcpServers`、Codex TOML、OpenCode `mcp`）原子无损合并写入 `shellbeam` 条目；写前严格限制 `0600` 权限、保留软链接目标与注释、失败自动回滚快照，撤销或降权同步时自动吊销旧令牌并精准清理配置文件。
- **全新「AI 集成」设置分区与清爽 MCP 界面**：
  - 侧栏「集成」更名为 **AI 集成**，通过二级标签页统一管理 **AI 助手** 与 **Agent 接入 (MCP)**，从「高级」中移出原本冗长堆叠的 MCP 表单。
  - 重做 MCP 界面为 `本机 Agent | 自定义接入 | 已授权 | 审计日志` 四个清晰分区；默认「本机 Agent」单卡即可切换三档权限预设（`仅缓存` / `只读排查` / `完整运维`）、一键开放全部已检测 Agent，或按行单独接入、更新与二次确认断开。
- **iPhone Duo 右侧竖栏专属适配与移动端体验修复**：
  - 严格依据 iOS `UITraitCollection.verticalBarEdge` 适配 iPhone Duo 外屏与内屏横屏（不影响安卓折叠屏与普通 iPhone/iPad）：隐藏左侧栏与空闲桌面顶栏，将导航优雅收纳至右侧竖条（避开顶部时间与信号状态区，顶部为搜索与主题切换，底部为 5 个拇指可达导航图标）。
  - 统一桌面与折叠屏收起侧边图标栏的全部图标与按钮尺寸并加上 `shrink-0`，彻底修复横屏矮视口下图标被挤压变形和主机页头部按钮错位问题。
  - 修复 iOS 触屏宽屏点击输入框自动放大页面的问题，为保管库解锁错误补全中英文国际化提示，并修正移动端「我的电脑」未初始化设备的提示文案。

## 升级说明

应用标识保持 `app.shellbeam`，直接升级即可无缝保留现有保管库、主机、凭据、AI 会话与已授权的 MCP 客户端；如需启用一键本机 Agent 接入，前往 **设置 → AI 集成 → Agent 接入 (MCP)** 即可。iOS 用户请通过 [TestFlight 公开测试链接](https://testflight.apple.com/join/FfZabFz1) 更新。

## English

ShellBeam v0.1.20 introduces a **Unified Local Agent Registry** with **one-click lossless MCP configuration**, consolidates AI Assistant and MCP into a redesigned **AI Integrations** settings area, and polishes **iPhone Duo** trailing vertical-bar and mobile ergonomics:

- **Unified Local Agent Registry & One-Click Safe MCP Setup**:
  - Single source of truth across Rust (`src-tauri/src/agents.rs`) and TypeScript (`src/lib/agents.ts`) shared by AI Assistant CLIs and local MCP agents (**Claude Code, Codex CLI, Antigravity, Cursor, Gemini CLI, OpenCode, Devin CLI, Claude Desktop**).
  - Automatically detects installed local agents, issues an independent token per agent, and atomically merges only the `shellbeam` entry across JSON (`mcpServers`), Codex TOML, and OpenCode schemas — enforcing `0600` permissions before writing, preserving symlinks and inline comments, restoring prior snapshots on failure, and revoking superseded tokens + cleaning config entries on disconnect.
- **Redesigned AI Integrations & Streamlined MCP UI**:
  - Renamed **Integrations** to **AI Integrations** with unified **AI Assistant** and **Agent Access (MCP)** sub-tabs, removing the stacked MCP forms from **Advanced**.
  - Rebuilt MCP settings into focused tabs (`Local Agents | Custom Setup | Authorized | Activity`) featuring a compact 3-level permission preset bar (`Cached only`, `Read-only`, `Full ops`), one-click connect-all, and per-agent connect / sync / two-click disconnect controls.
- **iPhone Duo Trailing Vertical Bar & Mobile Polish**:
  - Follows iOS `UITraitCollection.verticalBarEdge` on both iPhone Duo outer display and inner landscape (without altering Android foldables or standard iPhone/iPad layouts): hides the left sidebar and idle desktop tab bar, placing quick search, theme toggle, and the 5 primary tabs inside a clean trailing vertical dock below the system status cluster.
  - Unified icon and button geometry with `shrink-0` across the collapsed icon rail so short landscape screens never crush icons, and fixed Hosts header alignment.
  - Disabled WebView input-focus auto-zoom across touch screens, localized vault unlock error messages, and corrected mobile Companion device initialization copy.
