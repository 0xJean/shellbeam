# ShellBeam v0.1.14

本次版本重点优化了 SSH 密钥认证兼容性与凭据录入体验，支持本机默认密钥自动回退、跨平台原生 `~/.ssh` 文件选择、`.pub` 公钥误填拦截、自定义 Vault 凭据名，并完善了跨端 `SSH Agent` 使用提示。

- **SSH Agent 自动回退本机默认密钥**：使用 `Agent` 认证时，若系统 `ssh-agent` 未加载密钥或无匹配身份，自动按 OpenSSH 顺序尝试本机 `~/.ssh/{id_ed25519,id_ecdsa,id_rsa}` 默认私钥，行为与系统 `ssh` 终端保持一致，并修复多密钥认证时的部分成功状态处理。
- **原生跨平台 SSH 私钥文件选择**：
  - 主机表单私钥模式新增「选择私钥文件」按钮，macOS 默认打开 `~/.ssh` 并自动显示隐藏文件（`NSOpenPanel`），Windows / Linux 默认定位至 `%USERPROFILE%\.ssh` / `~/.ssh`；
  - 移除 `.pem` 扩展名过滤限制，可直接选取无后缀私钥文件（如 `id_rsa`、`id_ed25519`），选中后自动以文件名预填 Vault 凭据名。
- **`.pub` 公钥误粘贴 / 误选防护**：粘贴或选择 OpenSSH 公钥（如 `ssh-rsa`、`ssh-ed25519` 或 `.pub` 文件）时立即提示错误并阻止保存，误选 `.pub` 文件时自动指引改选同目录对应私钥。
- **手动输入密码 / 私钥支持显式自定义凭据名**：为 Vault 凭据名称输入框补充清晰的标签提示，便于统一管理与复用密码/私钥凭据。
- **跨端 SSH Agent 同步说明与移动端提示**：明确说明 `Agent` 模式仅依赖本机密钥、不会跨设备同步；移动端查看 `Agent` 认证主机时展示醒目提示并提供快捷编辑入口，方便切换为可同步的 Vault 凭据。
- **发布流程优化**：Release 工作流在所有平台打包及验收测试通过后直接公开发布 GitHub Release。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和历史审计记录。

## English

ShellBeam v0.1.14 improves SSH authentication compatibility and credential onboarding with OpenSSH-style default key fallback, a native cross-platform `~/.ssh` key file picker, `.pub` public-key guardrails, clearer Vault credential naming, and cross-device SSH Agent guidance:

- **Fallback to Default `~/.ssh` Keys in Agent Mode**: When `ssh-agent` has no loaded or matching identity, `Agent` auth automatically falls back to default local keys (`~/.ssh/id_ed25519`, `~/.ssh/id_ecdsa`, `~/.ssh/id_rsa`) matching native OpenSSH CLI behavior, and fixes partial-auth handling across multiple identities.
- **Native Cross-Platform SSH Private Key Picker**:
  - Adds a **Choose key file** action directly in the Host Form; defaults to `~/.ssh` with hidden files shown on macOS (`NSOpenPanel`), and `%USERPROFILE%\.ssh` / `~/.ssh` on Windows and Linux.
  - Removes restrictive `.pem`-only extension filtering so extensionless private keys (`id_rsa`, `id_ed25519`) can be picked directly and pre-fill the Vault credential name.
- **Public Key (`.pub`) Guardrails**: Detects pasted OpenSSH public keys (`ssh-rsa`, `ssh-ed25519`, etc.) inline and blocks saving, and rejects `.pub` files picked from disk with a pointer to the sibling private key.
- **Clear Customizable Vault Credential Naming**: Adds an explicit visible label for the Vault credential name input on both manual password and private key entry.
- **Cross-Device SSH Agent Guidance**: Clarifies that `Agent` auth stays local and does not sync keys across devices, and adds an inline notice card with an Edit shortcut on Mobile Host Detail for `Agent`-authenticated hosts.
- **Direct Release Publishing**: Publishes GitHub Releases directly once all platform builds and packaged acceptance checks pass.
