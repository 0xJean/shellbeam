# ShellBeam v0.1.9

## 更新内容

- **手机布局：** 手机宽度下可以进入工作空间，会话页可在终端、工作空间和浏览器之间切换；底部导航不再遮挡内容，多个页面在小屏上不再溢出。
- **iPhone Duo 适配：** 外屏和内屏横向时，底部标签栏按系统要求移到侧边竖条；内屏竖向仍在底部。iOS 构建改用 UIScene 生命周期，最低系统版本改为 iOS 15。
- **模式切换保留状态：** 终端、工作空间和浏览器之间切换，或窗口跨过手机宽度时，终端输出、AI 面板和浏览器页面不再被重置。
- **新版本提醒：** 桌面端和 Android 启动后及每 12 小时检查一次 GitHub Releases，有新版本时在侧边栏（手机布局在设置页）提示，并可在设置中关闭自动检查。只提醒，不自动下载或安装。
- **监控服务初始化：** 初始化新服务时可填写一次性安装令牌，以配合要求令牌的 ShellBeam Server。

## 安全修复

- **应用命令仅限本地界面：** 内置浏览器中打开的网页不能再调用应用命令（如读取 Vault）。同时升级 Tauri 至 2.12.5，并启用正式的内容安全策略。
- **局域网同步：** 配对改为密钥交换加双方确认验证码，所有请求都需要认证并防重放。导出含 Vault 的完整备份时，本机会弹窗确认。
- **AI 自动执行：** 判定“只读命令”更严格，带未知参数、控制字符、环境变量或网络访问的命令都需要手动确认。
- **SFTP 下载：** 修复异常文件名可能让下载写到所选目录之外的问题。
- **生物识别解锁：** macOS 和 iOS 改用只认生物识别的钥匙串项，设备密码不能再代替指纹或面容。
- **Android 备份：** 关闭系统云备份和设备迁移，同步密钥和 Vault 文件只保存在本机。
- **依赖：** CI 中的 Action 固定到具体提交，开发服务器限制为本机访问，并升级了有安全公告的依赖。

## 升级须知

- **局域网同步需要重新配对：** 旧的配对会失效，两台设备都要升级到 v0.1.9 后重新配对。新旧版本之间无法同步。
- **macOS 本版不提供 Touch ID 解锁：** 新的钥匙串项需要应用签名带额外授权，本版尚未加入，因此 macOS 上只能用主密码解锁。旧的 Touch ID 设置会被清除。
- **需要重新开启生物识别：** iOS 用户升级后需在设置中重新开启 Face ID / Touch ID。
- **Android 数据不再随备份迁移：** 换机时请通过同步或重新添加主机来恢复。
- **部分 AI 自动执行命令改为手动确认：** 例如 `curl`、`ping` 以及带 `$VAR` 或通配符的命令。
- 应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控记录和审计。桌面升级不升级或重新部署 ShellBeam Server、监控探针和服务端扩展。

## Highlights

- Phone layout: the workspace is reachable, sessions switch between terminal, workspace and browser, and the bottom navigation no longer covers content.
- iPhone Duo: the tab bar moves to the side strip where iOS places vertical bars. iOS builds adopt the UIScene lifecycle and require iOS 15.
- Terminal output, the AI panel and browser pages survive mode switches and window resizes.
- Desktop and Android remind you when a newer release is out. Reminder only, no self-update.
- Security: app commands are limited to the local frontend, LAN sync uses authenticated pairing, AI auto-run is stricter, SFTP downloads stay in the chosen folder, biometric unlock no longer accepts the device passcode, and Android excludes app data from backups.
- Upgrade notes: re-pair LAN sync on both devices; Touch ID unlock is not available on macOS in this release; iOS users re-enable Face ID / Touch ID.
