# ShellBeam v0.1.13

本次版本重点提升了移动端（Android / iOS）的兼容性、交互体验与功能完整度，同时修复了本地 SSH 配置导入误扫 Git 托管配置与探针告警操作审计并发竞态问题。

- **本地 SSH 配置导入智能过滤代码托管平台**：导入 `~/.ssh/config` 时自动识别并排除 GitHub、GitLab、Gitee、Bitbucket、Codeberg、Azure DevOps、AWS CodeCommit 等代码托管域名与 `User git` 多账号别名配置，避免无法交互式登录的 Git 仓库别名污染主机列表。
- **修复探针告警关闭/确认的并发审计竞态**：将原生 `local_ops_alert_action` 与同主机后台 30 秒规则扫描串行化，并确保审计日志 `completed` 落库完成后再同步更新 UI 缓存，彻底消除 `REVISION_CONFLICT` 导致已关闭告警被误记为失败的竞态问题。
- **Android / iOS 底层兼容性修复**：
  - 移动端禁用本地 PTY 终端并隐藏不支持的本地终端与内嵌浏览器入口，避免实机报错；
  - 修复 Android SFTP 本地文件根目录获取（`local_home_dir` 自动回退至系统文档/应用数据目录）；
  - Android 补齐 `POST_NOTIFICATIONS` 通知权限、`adjustResize` 软键盘模式、Edge-to-Edge 系统栏与 IME 安全区适配，以及系统返回手势站内多级页面回退。
- **移动端体验与功能补齐**：
  - 手机终端工具栏新增**一键粘贴**与**收起软键盘**按钮，终端支持**双指捏合缩放字号**；
  - 手机主机详情页接入**集中探针管理弹窗**与**本地告警列表（支持直接确认/关闭）**；
  - 移动端补齐**总览仪表盘**入口、主机页顶部**快捷保险库切换与一键锁库**，以及审计日志窄屏纵向卡片视图。

## 升级说明

应用标识保持 `app.shellbeam`，沿用现有 Vault、主机、凭据、MCP 授权、监控配置和历史审计记录。

## English

ShellBeam v0.1.13 delivers major mobile (Android / iOS) compatibility, UX, and feature parity improvements alongside fixes for local SSH config import and probe alert audit concurrency:

- **Filter Git Hosting Entries from SSH Config Import**: Automatically excludes GitHub, GitLab, Gitee, Bitbucket, Codeberg, Azure DevOps, AWS CodeCommit, and `User git` repository aliases when scanning `~/.ssh/config`.
- **Eliminate Probe Alert Audit Concurrency Race**: Serializes native `local_ops_alert_action` mutations against background 30s rule scans and commits the `completed` audit entry before updating renderer state, preventing `REVISION_CONFLICT` from misreporting completed alert closures as failed.
- **Android / iOS Compatibility Fixes**:
  - Disables unsupported local PTY shells and hides desktop-only Local Terminal / Embedded Browser controls on mobile OS builds.
  - Fixes Android SFTP `local_home_dir` by falling back to platform document/app-data directories.
  - Adds Android `POST_NOTIFICATIONS` permission, `adjustResize`, Edge-to-Edge `systemBars` + `ime` insets padding, and in-app LIFO back-gesture routing.
- **Mobile UX & Feature Parity**:
  - Adds **Paste** and **Hide Keyboard** buttons to the mobile terminal toolbar plus **2-finger pinch-to-zoom** terminal font scaling.
  - Brings **Probe Management** (`HostProbeManageDialog`) and live **Local Alerts** (with Acknowledge / Close actions) into Mobile Host Detail.
  - Exposes **Fleet Dashboard** in Mobile Tools, adds quick Vault switch & lock controls in Mobile Hosts, and renders responsive vertical audit cards on narrow viewports.
