# ShellBeam v0.1.19

本次版本推出「手机直连电脑（Desktop Companion Bridge）」与内置零配置 `iroh` P2P 加密穿透，全面重构移动端、折叠屏与桌面窄窗交互布局，升级移动端暗色工作空间视觉，并新增非侵入式版本更新提醒。

- **手机直连电脑（Desktop Companion Bridge）与内置 `iroh` P2P**：
  - 纯 Rust 集成 `iroh` P2P 中继穿透，支持 **局域网（LAN）→ Tailscale → `iroh` P2P** 三层路由自动择优与断线无感切换，无需配置公网 IP 或额外 VPN。
  - 复用 X25519 + HKDF + AES-256-GCM 端到端加密通道；移动端内置应用内二维码扫描器，一扫即连桌面端。
  - 桌面端活跃终端会话与 AI 助手状态实时推送至手机，支持全屏远程查看、键盘接管（默认手机自适应排版）、远程调用桌面端本地 AI CLI，以及细粒度设备权限管理（撤销权限即时断开活跃流，旧同步设备升级默认最小权限）。
- **移动端、折叠屏与桌面窄窗响应式重构**：
  - 将「设备形态能力」与「三档视口宽度（`< 768px` / `768–1119px` / `>= 1120px`）」解耦，移动端和平板（含折叠屏展开态）不再误启桌面入站监听或展示桌面本地终端按钮。
  - 新增可折叠 60px 侧边图标栏（Icon Rail），中屏自动收起并支持浮层抽屉切换，宽屏支持手动折叠。
  - 全面修复设置页、外观选择器、代码片段、我的电脑与 SFTP 文件页在折叠屏和窄窗下的挤压截断问题；折叠屏展开态保留可折叠终端快捷按键条，窄窗下 AI 助手与右侧信息栏自动切换为抽屉浮层。
- **移动端底部导航、会话启动器与暗色工作空间升级**：
  - 精简重构底部导航栏为 **主机 | 会话 | 电脑 | 工具 | 设置**，将 SFTP 文件传输收敛至「工具」页顶部。
  - 重做无活跃会话页为「会话启动器」，可直接一键接入已连接电脑的实时终端或搜索主机发起 SSH 连接；修复返回主机页黑屏、无会话点击「会话」Tab 无法停留、活跃终端底部栏遮挡软键盘以及折叠/展开态会话不同步等问题。
  - 替换移动端保管库切换器、下拉选择器及文件新建/重命名/改权限等系统原生弹窗为自适应主题自定义组件。
  - 补全暗色模式下移动工作空间语义色板，重塑玻璃质感工作空间应用图标，并隐藏移动端不适用的桌面内置浏览器入口。
- **非侵入式应用更新提醒**：
  - 新增顶部更新提示胶囊、全局非阻塞更新 Toast 与更新日志弹窗，支持直接浏览最新版本说明、一键跳转下载或当前会话稍后提醒，并在侧栏设置入口展示红点提示。

## 升级说明

应用标识保持 `app.shellbeam`，直接升级即可无缝保留现有保管库、主机、凭据、AI 会话记录与偏好设置。既往仅配对过「同步」的旧设备在升级后默认不会自动获得桌面终端控制权限，如需手机直连可在桌面端「我的电脑」中按需开启。

## English

ShellBeam v0.1.19 introduces the **Desktop Companion Bridge** with built-in zero-config `iroh` P2P encrypted relay, overhauls the mobile, foldable, and narrow-desktop responsive experience, refines the dark mobile workspace UI, and adds non-blocking in-app update reminders:

- **Desktop Companion Bridge & Built-in `iroh` P2P**:
  - Pure-Rust `iroh` P2P transport with automatic 3-tier route selection and failover (**LAN → Tailscale → `iroh` P2P**), requiring no port forwarding or third-party VPN.
  - End-to-end encrypted X25519 + HKDF + AES-256-GCM multiplexed bridge with an in-app mobile QR scanner for one-scan pairing.
  - Real-time push of active desktop terminal sessions and AI assistant state to mobile, full-screen remote terminal viewing/control, remote access to desktop-installed AI CLIs, and per-device permission controls (revoking permissions immediately closes active streams; legacy sync-only peers upgrade with least-privilege defaults).
- **Mobile, Foldable & Narrow-Desktop Responsive Overhaul**:
  - Decoupled device capability from 3-tier viewport breakpoints (`compact < 768px`, `medium 768–1119px`, `wide >= 1120px`), ensuring mobile/foldable/tablet devices never expose desktop-only host listeners or local shell actions.
  - Added a collapsible 60px Icon Rail sidebar (auto-compact with overlay drawer on medium widths, manual toggle on wide desktops).
  - Fixed multi-column crushes across Settings, Appearance Picker, Snippets, Companion Center, and SFTP; kept the collapsible mobile terminal key toolbar available on unfolded foldables; turned the AI Command Bar and right info sidebar into overlay drawers on narrow widths.
- **Mobile Navigation, Session Launcher & Dark Workspace Polish**:
  - Reorganized the mobile bottom tab bar to **Hosts | Sessions | Desktop | Tools | Settings**, moving SFTP to the top of Tools.
  - Redesigned the empty Sessions screen into a fast Session Launcher (live desktop sessions + instant host search/connect) and fixed back-navigation black screens, tab bounce-back with 0 sessions, bottom bar overlapping the soft keyboard during active terminals, and fold/unfold session sync.
  - Replaced remaining native mobile browser/WebView popups (vault selector, `<select>` menus, and file manager `window.prompt` dialogs) with theme-adaptive custom UI.
  - Added missing dark-mode mobile workspace palette tokens, redesigned workspace app icons with refined tinted glass tiles, and hid the desktop-only Browser app on mobile.
- **Non-Blocking App Update Reminders**:
  - Added an unobtrusive top-bar update pill, global dismissible update toast, release-notes dialog, and compact rail settings badge so new versions are surfaced without interrupting active terminal work.
